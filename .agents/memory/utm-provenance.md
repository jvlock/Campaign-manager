name: UTM provenance
description: Boundaries on compiler provenance and taxonomy approval claims.
---

Do not claim verified parity with the Campaign Governance Foundation compiler or an official MSCI guide without inspecting that source and running its original parity fixtures.

**Why:** The Foundation source and tests were unavailable in this workspace. After a verified status check, the user explicitly authorized implementation from the supplied formulas instead of waiting for that source. Locally written formula tests do not establish external-source parity.

**How to apply:** Describe the implementation as specification-based. If authentic Foundation files arrive later, compare behavior and tests before making a parity claim.

Legacy category labels and locally assigned seed codes are not evidence of approved UTM conventions.

**Why:** The user requires exact category keys distinct from similarly named legacy categories, and explicitly separated category registration from later value population.

**How to apply:** Never silently alias legacy categories, seed values, or approve terms merely to make generation succeed. Keep governance actor attribution distinct from authenticated identity.
